# Ascel Bill

## Tech stack

- **Tauri 2** for the desktop application on Windows and macOS
- **Svelte 5, TypeScript, and Vite** for the interface, with system fonts
- **Rust** for invoice calculation, numbering, validation, and file operations
- **SQLite** for local records, atomic invoice issuance, stock movements, and backup snapshots

## About Ascel Bill

Offline-first billing software for Indian shops and small businesses. Ascel Bill is designed for the counter, where issuing an invoice, printing a copy, or recovering records after a computer failure needs to be straightforward.

Set up a business, add customers and stock items, and issue, print, or reopen invoices. The billing engine handles supported domestic GST sales and keeps B2B invoices that require an IRN in draft. The workspace can export a monthly sales register for an accountant and save or restore a local backup.

Choose an A4 template or a compact A5 or A6 laser layout. Set print defaults in Settings and pick a different layout on any invoice. Add a customer from the invoice or import contacts from CSV with a duplicate check.

The overview shows live sales, customer activity, and stock levels from the local workspace. Receive stock or enter a physical count from the stock alert list. The app supports English, Hindi, and Bengali. New invoices start in INR. Businesses without a GST registration can opt in to USD for ordinary invoices, with separate totals and sales exports by currency.
