# Launch Ascel Bill for offline counters

**Product plan for approval · 25 November 2026**

Ascel Bill should help an Indian shop find an item, confirm GST, issue and print the invoice, then give its accountant a reconciled sales register. **Use Tauri 2, Svelte 5 and TypeScript, Rust, and SQLite**, subject to installation, printing and performance tests on a 4 GB Windows PC. Launch with one GSTIN and one active issuing computer per business, with Windows x64 first and a signed macOS build validated for Apple Silicon and eligible Intel Macs. Cover ordinary domestic taxable-goods sales for regular GST-registered merchants outside mandatory e-invoicing. Test **₹1,499 founding and ₹1,999 standard per business per year, before GST**, with no mandatory cloud service for local billing. The [clickable design prototype](../prototype/index.html) is ready to review with sample data. Production development begins after approval.

## The first release serves one busy counter

The live Ascel Bill site already presents no-login invoicing, GST calculations, print, GSTR-1 preparation, backups, and a mobile preview. The public browser demo uses separate `localStorage` collections for data such as invoices, customers and audit history. Carry forward the green identity and familiar product vocabulary. Verify access to the original source and its export format before estimating code reuse or moving customer data. In the desktop app, issue the invoice and its associated records in one database transaction. Use explicit place of supply in the form and give the accountant traceable working papers. The live site's sample testimonials and mobile preview serve as design material. [Ascel Bill site](https://ascelbill.ascelstack.com/) · [Public web app](https://ascelbill.ascelstack.com/app/) · [Delivered app bundle](https://ascelbill.ascelstack.com/_astro/App.7gVXxJF7.js)

Start with hardware, electronics accessories and similar stock-led counters with a clerk or owner on one PC and an external CA. The MVP includes shop setup, GSTIN and business details, searchable customers and items, HSN and rates, basic stock movements, B2B and B2C sales, invoices and linked correction documents, cash and operator-confirmed UPI or credit payment records, A4 PDF/print, a sales register, and backup and restore. Include tax-inclusive and tax-exclusive entry where the CA fixtures pass. Pilot a single thermal printer model only if stores need it and its template can carry the applicable invoice fields. Keep full accounting, payroll, native mobile, AI assistance, actual payments processing, and online IRP/e-way bill connectors in later scope. Confirm catalogue import format and printer models during discovery.

The third lets the clerk save an unnumbered draft while issuance is paused. Review the issued sample and print view under **Invoices**, export a sample CSV from **GST reports**, and download and inspect a sample JSON backup. The design uses fictional records and demonstrates the workflow, including backup inspection, with native persistence, actual printer operation and compliance validation reserved for the approved build. ## Tauri is the best first test for 4 GB Windows PCs

Tauri 2 uses the system WebView2 on Windows and WKWebView on macOS. That reduces what the standard installer needs to carry and gives one UI source for both systems. Tauri published core 2.12.7 on 18 November 2026, and Wails reached stable v3 in October. Recent releases establish active maintenance. Ascel Bill's packaging and memory targets still need measurement. Keep fonts and assets local, use one main window, paginate or virtualize long lists, and query indexed records. Select the PDF engine using the same 10-line, multipage and local-script fixtures for Windows and Mac. ## One local database keeps issuance and recovery consistent

Create and open the database in the OS application data directory. Keep the Tauri bridge to explicit Rust commands, use parameterized SQL and bundle a SQLite version that includes the documented WAL-reset fix, **3.51.3 or a supported fixed backport**, verified against the binary. Store money in integer paise with sufficient decimal precision for quantities, tax and intermediate computations. In one SQLite transaction, allocate the final financial-year number and persist the immutable invoice and line snapshots, customer and rate details, totals, payment and stock effects, and audit event. Give each issue request an idempotency key. Start printing after commit so printer failure allows a clean reprint. Test forced termination before and after commit, double submission, disk-full handling, continuity after restart and valid prior-version backup restoration. [SQLite WAL and fixed versions](https://sqlite.org/wal.html#walresetbug)

Use the SQLite Online Backup API to generate a consistent snapshot. Package it with schema version, checksum and backup timestamp, with an encrypted portable archive option and a tested recovery method. Keep rotating local copies and prompt the user to export to a separate drive. Restore to a staged location, verify integrity and compatibility, preserve the current database and swap only under exclusive access. Test cross-platform restore and migration with an identical issued-invoice register. When replacing a billing computer, transfer the backup and explicitly close issuing on the original. Keep the active SQLite file local to its machine and sync only versioned exports or structured application records. [SQLite backup API](https://sqlite.org/backup.html) · [SQLite file integrity guidance](https://sqlite.org/howtocorrupt.html)

Cross-device delivery first means the same product is available on Windows and Mac, with an offline transfer path. When merchants need phone or home access, offer an opt-in read-only companion with last-sync status. Multiple offline issuing tills require device identity, distinct accountant-approved series or number allocations, immutable event records, idempotent synchronization, a transactional outbox and explicit rules for duplicate, stock and payment conflicts. Test a full-day partition, partial reconnect and restore before enabling it. A second computer can view its most recently synced data while offline, with freshness visible.

## GST rules determine which sales can complete offline

For the initial scope, confirm merchant eligibility with a CA. Apply GST based on supplier location and the legal place of supply, with intra-state CGST plus SGST or applicable UTGST, and interstate IGST. For ordinary goods sales with movement, delivery generally determines where movement ends. The rules for unregistered recipients use the recorded invoice address or the supplier location when that address is absent, with CBIC guidance for differing billing and delivery addresses. Restrict onboarding or route to review for unsupported third-party delivery, cross-border supplies, composition, exempt or mixed workflows, reverse charge, special valuation or cess. [IGST Act sections 7, 8 and 10](https://upload.indiacode.nic.in/showfile?actid=AC_CEN_2_2_00043_201713_1517807328116&filename=a2017-13.pdf&type=actfile) · [CBIC Circular 209/03/2024](https://www.gstcouncil.gov.in/sites/default/files/2024-09/circular-no-209-03-2024.pdf)

Validate Rule 46 fields and print copies with the CA. Capture supplier and recipient identity and address where applicable, GSTIN, date, HSN and quantity/UQC, taxable value after eligible discounts, component rates and amounts, place of supply, delivery address, reverse-charge status, and authentication as applicable. Use a consecutive financial-year invoice identifier of at most 16 characters, with the permitted characters and no reuse after cancellation. Test B2C disclosure thresholds, HSN rules, exempt and unsupported cases, duplicate clicks, returns and linked credit or debit notes. Keep an audit log and design retention around the usual statutory 72 months from the annual-return due date, plus applicable extensions. Use effective-dated rates, document calculation order and rounding, and apply section 170 rounding at the applicable statutory boundary. A simple fixture is ₹1,000 at 18%, yielding ₹90 CGST and ₹90 SGST intrastate or ₹180 IGST interstate, with ₹1,180 payable in either case. [CBIC Rules 46–49](https://cbic-gst.gov.in/pdf/24092021-CGST-Rules-2017-Part-A-Rules.pdf) · [CBIC HSN requirements](https://cbic-gst.gov.in/pdf/press-release/Press-release-HSN-code-SAC-issue.pdf) · [CGST Act](https://upload.indiacode.nic.in/showfile?actid=AC_CEN_2_2_00042_201712_1517807328102&filename=a2017-12.pdf&type=actfile) · [Rule 53](https://taxinformation.cbic.gov.in/content-page/explore-rules/1000144/1000001) · [Rule 56](https://taxinformation.cbic.gov.in/content-page/explore-rules/1000149/1000001)

Make **IRN required** a draft-only flow during an outage. Where Rule 48(4) applies, obtain the authorized IRP's IRN and signed QR before issue. The mandate uses PAN-wide aggregate turnover exceeding ₹5 crore in any preceding financial year from 2017–18 for the notified class, with exemptions. The separate 30-day portal restriction for ₹10 crore-and-above AATO governs reporting acceptance. For a shipment requiring an e-way bill, use the official portal and record the reference before dispatch. Generally the rule applies over ₹50,000 in consignment value, subject to inclusions, exceptions and state rules. West Bengal's intrastate threshold moved to over ₹50,000 effective 1 June 2026 with a job-work exemption. Treat invoice and shipment status independently. Review state rules for the pilot and link to the alternate official portals for outages. [Mandate amendment](https://einvoice6.gst.gov.in/content/wp-content/uploads/2023/05/GST-notification-10-central-tax-english-2023.pdf) · [GSTN e-invoicing guide](https://tutorial.gst.gov.in/downloads/news/e_invoice_overview.pdf) · [IRN 30-day advisory](https://d23z1tp9il9etb.cloudfront.net/download/gstlaw/download1731066652.pdf) · [NIC e-way bill FAQ](https://docs.ewaybillgst.gov.in/html/faq1.html) · [West Bengal circular](https://comtax.wb.gov.in/GST/GST_Trade_Circulars/WBGST_TC_01_2026_20260525.pdf) · [Official continuity advisory via authorized IRP](https://einvoice6.gst.gov.in/content/gstn-issues-advisory-on-business-continuity-for-e-invoice-and-e-waybill-systems/)

Release an accountant sales register with drill-through to document numbers and period reconciliation. Validate supported GSTR-1 working papers for Tables 4, 5 and 7 where applicable, HSN summaries in Table 12, document reporting in Table 13, and relevant notes and amendments. Ask the CA to reconcile one representative monthly export with the underlying records and confirm the live portal schema before advertising a portal-ready import. Filing goes through the official portal. [GST Portal GSTR-1 guide](https://tutorial.gst.gov.in/userguide/returns/Creation_of_Outward_Supplies_Return_in_GSTR-1.htm) · [GSTN Tables 12 and 13 advisory](https://tutorial.gst.gov.in/downloads/news/updated_advisory_hsn_table12_25042025.pdf)
